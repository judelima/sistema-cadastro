 Sistema de Cadastro de Usuários

Objetivo
Sistema desenvolvido para gerenciamento e cadastro de usuários, permitindo inclusão, consulta e validação de dados.

 Funcionalidades
- Cadastro de novos usuários
- Consulta de registros
- Validação de dados

 Tecnologias
- Java
- Git e GitHub

Como Executar
1. Certifique-se de ter o JDK instalado.
2. Compile o arquivo com: `javac src/Main.java`
3. Execute com: `java -cp src Main`

Documentação
A especificação de requisitos está disponível na pasta [`docs/`](./docs/).
